# Agent Note: 第六期记忆拓展——认知、经验与故事长期演化

Status: proposed

## Problem

基线 v3.353.0 / `a6025ba`，2026-10-22。当前不是“没有记忆功能”，而是拥有事实、认知传播、关系、因果、正史、资料与假设底座之后，如何产生新的叙事能力。本期新增机制必须可独立使用，不把手机展示同一数据计成另一项记忆功能。

[源码证据与去重裁定](../../../../docs/planning/2026-10-22-product-evidence-v6.md)限定了已验证范围。未在已查入口看到某种完整体验，不等于全仓零实现；以下是新产品提案，不是九条已复现故障。与[优化计划](../architecture/2026-10-22-product-optimization-v6.md)共享现有所有者。

## Proposal

### M6-X1 · 信念演化：人物可以有理由地误解，也能有过程地改观（P1 / XL）

- **依据与需求**：[M-E4/M-E3](../../../../docs/planning/2026-10-22-product-evidence-v6.md#memory-evidence)。knowledge-trace 与视角卡已有知道/听说/误信的区分；新能力是保留人物对证据的解释与改观过程，而不是知情状态一更新，所有人立刻相信同一真相。
- **机制与完整体验**：分开世界事实、人物所见证据、人物解释及确信程度；新证据可以加强、动摇或不改变信念，转变必须带人物视角下的理由。原生页可编辑解释并预览它怎样改变下一次发言材料。
- **不重复什么**：M6-O4描述经历，X1描述对经历的解释；不重做证词对照，不把模型推断升级为心理事实。
- **落点/依赖**：`knowledge-trace.js`、`perspective-card.js`、`testimony-board.js`和现有角色记忆；依赖 M6-O5，接 M6-O6 消费。
- **验收下限**：① A收到反证、B未收到，两人的认知不同且可回看形成过程；② 不可靠转述不会因重复出现而强制改观；③ 作者改变某次解释后，未来生成使用新版而历史视角不改写。至少两类人物性格与三次证据更新的持续试写对照。
- **代价/不做**：不模拟真实人的心理画像；可信度是作者可调的叙事参数，不宣称科学心理测量。

### M6-X2 · 经验与习惯学习：记住怎么做、何时例外，而不只记住做过（P1 / XL）

- **依据与需求**：[M-E2/M-E9](../../../../docs/planning/2026-10-22-product-evidence-v6.md#memory-evidence)。lifeDetails已有生活偏好文字与时效。人物长期共同生活需要可情境化复用的行为经验，例如“平日喝茶，但排练前不喝”，不能从一次选择写成终身习惯。
- **机制与完整体验**：从多次有出处的行动提炼情境—做法—结果候选，保留例外、学习阶段与失效条件；作者确认后在合适场景调用，角色实践失败可修订经验。原生页支持查看“为什么认为这是习惯”。
- **不重复什么**：不同于周期日程的时间重复、目标前置条件和静态偏好标签；新增程序性经验的形成、应用与修正。
- **落点/依赖**：`memory-core.js::addLifeDetail`、角色记忆、事实引用与材料包；依赖 M6-O1，O5提供时间背景。
- **验收下限**：① 同类三次实践产生候选，一次偶然事件不直接定型；② 指定情境例外优先于一般习惯；③ 一次失败后可修订或停用做法，重开及百楼后仍保留证据与例外。生成中能实际采用做法，而非只显示“习惯已记录”。
- **代价/不做**：不自行学习危险现实操作；范围限普通生活与虚构叙事经验，不把读到的说明当已掌握技能。

### M6-X3 · 条件后果推演：选择改变未来的哪些可能性（P1 / XL）

- **依据与需求**：[M-E4/M-E9](../../../../docs/planning/2026-10-22-product-evidence-v6.md#memory-evidence)。因果导航追溯已发生的边，目标树检查前提；新能力是在作者作选择前，看见有依据的延迟影响，而不是自动续写一个确定未来。
- **机制与完整体验**：把已确认约定、资源、关系条件与作者给定规则连成有限后果网络；动作提案输出直接变化、条件性后续、可能失去的选项及未知部分。随剧情证据出现，候选后果可兑现、落空或被替代。
- **不重复什么**：不同于 `dependency-closure.js` 的技术缓存失效，也不代替 M6-O9 当前路线管理；此项推演的是故事后果，不是修复依赖。
- **落点/依赖**：`causal-chain.js`、`commitment-ledger.js`、`goal-tracker.js`、`fact-version.js`；依赖 M6-O5/O9，作者入口独立可用。
- **验收下限**：① 接下两项冲突承诺，可展示时间占用和条件后果，但不提前写成违约；② 新证据解除冲突后投影改变；③ 未提供因果规则的事件保持未知，不给伪精确概率。完整演示选择→预览→确认→后续证据→兑现/落空。
- **代价/不做**：有界深度防指数膨胀；不训练通用世界模拟器，不以推演替代玩家选择。

### M6-X4 · 多步反事实实验：比较两条人生路线，而非只试写两段话（P2 / XL）

- **依据与需求**：[M-E10](../../../../docs/planning/2026-10-22-product-evidence-v6.md#memory-evidence)。已有假设工作集、双栏试写和正史选择；新机制是保持同一初始条件，对局部干预进行多步可继续实验，解释差异何时产生。
- **机制与完整体验**：冻结可用事实引用，建立显式干预集及每步假设/结果；两路线共享未改动前提，逐步比较关系、资源、目标与认知变化。可只带走研究结论，也可由既有正史选择流程确认部分成果。
- **不重复什么**：不是多加几个工作集/结果长度，不再申报 M5-X7；新增逐步运行、可重复条件对照与差异归因。归因只指规则/证据依赖，不声称模型随机输出能证明现实因果。
- **落点/依赖**：`hypothesis-workspace.js`、`branch-semantics.js`、`branch-canon.js`、`impact-preview.js`；依赖 M6-O5/X3。
- **验收下限**：① 同一筹展起点分别“改期/不改期”各推进三幕，可定位首次分歧；② 修改第二步仅重算受影响后续；③ 丢弃实验后正史事实、人物知识与未完约定无新增。重开可继续，确认选择沿现有正史入口。
- **代价/不做**：模型随机性需记录配置、区分重放与重新生成；不承诺每次文本逐字相同。

### M6-X5 · 群体与制度记忆：组织不会随一次群聊结束而失忆（P1 / XL）

- **依据与需求**：[M-E4/M-E9](../../../../docs/planning/2026-10-22-product-evidence-v6.md#memory-evidence)。现有多人共通知情、关系与约定以人/事件为主；社团、家庭团队或店铺还需要职责、决议、规则与更替史，不能等同于所有成员知道同一件事。
- **机制与完整体验**：以组织实体关联成员任期、授权职责、正式决议、可变规则与惯例；群体声明和个人看法分开。换负责人时按组织可继承内容生成交接，而私人的误解不自动变成组织事实。
- **不重复什么**：不是再做群投票或共享记忆过滤；新增组织级持续身份与制度变迁。成员随时可不赞同组织决议。
- **落点/依赖**：实体词典、`knowledge-network.js`、`commitment-ledger.js`、`fact-version.js`；依赖 M6-O5，组织资料页与材料注入同批交付。
- **验收下限**：① 社团换负责人后职责继续但私人秘密不继承；② 临时决议到期不被当永久规则；③ 同名分会独立，跨卷交接可选择规则而不带走无权访问的个人材料。
- **代价/不做**：无须引入权限管理后台；组织约束只服务叙事，不自动代理现实机构行动。

### M6-X6 · 意象与意义变迁：同一地点、物件或话语能有不同分量（P2 / XL）

- **依据与需求**：[M-E4/M-E11](../../../../docs/planning/2026-10-22-product-evidence-v6.md#memory-evidence)。已有情绪曲线、旧事重现与物品履约；新需求是理解“旧车站第一次是离别、后来是重逢”这种含义迁移，而非再次命中地点关键词。
- **机制与完整体验**：把重复出现的对象关联到不同人物视角下的经历与意义；保留字面事实、作者确认的象征解释和纯候选三层。下一幕可选择呼应、反转或不提，使旧事以新的意义出现。
- **不重复什么**：不是再做 fated-recall 自动触发，也不是只画情绪折线；新增语义转变与人物差异的可编辑结构。
- **落点/依赖**：`fated-recall.js`、`recall-echo.js`、`narrative-pulse.js`、实体及经历引用；依赖 M6-O1/O4，消费进入 O6。
- **验收下限**：① 同一物件对A是约定、对B只是工具，生成不能混同；② 三次登场后含义可改变，历史解释仍可查；③ 作者否定象征解释后不继续反复强行呼应。做不少于六个意义变化场景的内容对照。
- **代价/不做**：不把所有重复词强制升级成文学母题，避免“万物皆伏笔”。

### M6-X7 · 缺席与期待记忆：记住该发生却尚未发生的事（P1 / XL）

- **依据与需求**：[M-E9/M-E3](../../../../docs/planning/2026-10-22-product-evidence-v6.md#memory-evidence)。已有未履行承诺与周期例外；但“没等到回信”与“没有记录到回信”不是一回事，生活叙事需要表达等待、错过和未兑现期待。
- **机制与完整体验**：期待必须带明确来源、观察窗口与可观察条件；到期后形成“已确认缺席/仍未观测/已解释延期”等不同经历。角色如何理解缺席可交 X1，不直接给对方定性。
- **不重复什么**：不是加强超时告警或周期提醒；新增把有据的未发生事件纳入人物经历与生成材料的语义。
- **落点/依赖**：`commitment-ledger.js`、知识轨迹、剧情钟与事件引用；依赖 M6-O5，X1可选增强解释。
- **验收下限**：① 剧情钟未前进时现实一天不触发失约；② 没看到对方日程时不能推断对方故意失约；③ 后续收到延迟回信后，旧等待仍是经历，但不再把当前状态写成“永远没有回应”。完整经过期待→等待→解释→后续生成。
- **代价/不做**：不把应用未读状态自动解释成角色冷落；不能从查询无命中证明事件未发生。

### M6-X8 · 回忆再理解：同一往事被重新讲述时，人物会获得新认识（P2 / XL）

- **依据与需求**：[M-E4/M-E10](../../../../docs/planning/2026-10-22-product-evidence-v6.md#memory-evidence)。已有事实纠错、争议证词与正史编辑；新的叙事维度是原事实没变，人物多年后却改变了对往事的理解。
- **机制与完整体验**：为一次回忆记录讲述时点、讲述者、所引用经历、当时解释与后来解释；区分事实修正、主观改观、叙事省略。生成可呈现不同人生阶段的回望，不反写原事件。
- **不重复什么**：X1管理当下信念，X8管理“回想这件事”的讲述版本与再理解历程；不是改设定工具，也不伪造记忆遗失。
- **落点/依赖**：`story-annual.js`、`perspective-card.js`、`testimony-board.js`、`relation-history.js`；依赖 M6-O1/O4/X1。
- **验收下限**：① 同一离别在两时点被不同解释，原文出处不变；② 用户修改回忆措辞不改变正史事实；③ 旧视角回放仍用当年解释，当前续写使用新理解。原生回忆编辑与生成链均可完成。
- **代价/不做**：不是故意让事实库失真；主观解释必须明确标注，不宣称人类记忆实验结论。

### M6-X9 · 跨时代传承：世界进入新阶段，留下来的不只是摘要（P2 / XL）

- **依据与需求**：[M-E12](../../../../docs/planning/2026-10-22-product-evidence-v6.md#memory-evidence)。已有长篇分卷、项目接续与正史选取；新能力是处理明确时间跨度下的人物更替、组织传承、物件去向和未完事业，而不是把所有旧状态原样搬走。
- **机制与完整体验**：作者指定时代跨度与变化规则，生成仍有效、自然到期、需作者决定、由后继者继承四类提案；每份传承带来源及接受者可知范围。可保留“他们不知道但世界仍受影响”的历史遗产。
- **不重复什么**：不是重新做接续包导入；新的是有时间与继承语义的世界转场，不擅自生成人物死亡、后代或重大人生事件。
- **落点/依赖**：`volume-continuation.js`、`project-registry.js`、`branch-canon.js`与事实/组织/物品所有者；依赖 M6-O5/X5。
- **验收下限**：① 跳到五年后，短期预约不照搬而组织规则可延续；② 新负责人继承事业但不是自动知道前任私人经历；③ 逐项选择并撤销一次转场，旧卷保持可读、新卷状态与选择一致。不得仅靠一份摘要演示结项。
- **代价/不做**：不填补所有空白年份；空白是作者选择空间，不是模型必须编满的缺陷。

## Delivery sequence

X1/X2优先做人物持续性；X3/X5/X7拓展选择与群体生活；X4/X6/X8/X9形成长期创作实验。依赖不允许反向成为“先做完九个底座才能使用”的借口：每项都须沿现有原生入口交付可独立体验的闭环。六个双仓批次见证据页。

## Alternatives considered

- **通用世界模拟器**：想象空间大，但现有证据不足以自动推进所有角色；选有界、可确认的后果与时代转场。
- **仅把新概念写入提示词**：试写成本低，无法解决跨楼持久化、解释变更和角色差异；允许先做内容实验，但不能据此标产品完成。
- **把每个新语义做成独立App/账本**：边界直观但造成重复所有者；本期优先给现有记忆对象增加引用与解释层，新入口围绕使用任务而非技术名词。

## Acceptance criteria

恰含 M6-X1～X9 九项，均需生产写入/回读/重开、原生操作和实际生成消费。每项至少三个场景验收按条执行；不能把同一后果预览分别在两个仓库算同一功能两次。相关手机端必须另有编排、交互与持续玩法才可独立验收。

## Risks

九项均具研究性，尤其信念、习惯和意义识别不能许诺可靠“理解人类”。先对照真实故事样本检验，再决定自动化程度。作者可覆盖、关闭或保留未知；生成只作为候选。遵循现有持久层、预算、引用与分支机制，不为本计划增设治理平台、外部数据库或不可控后台代理。
