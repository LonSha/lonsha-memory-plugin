## 本期统一纪律（九项共用，先于实现成立）

1. **候选不替角色选**：涉及「角色怎么说」的一律只产候选素材挂 `window.<Host>._xN`，绝不塞进上下文。
2. **桥只判不写**：判定归纯函数桥，写路径归宿主记账，桥零 IO。
3. **读不到 ≠ 没事**：不同失败态不塌陷成一个 `false`。
4. **空就是空**：不让空结果伪装成「暂无 / 正常」。
5. **文案唯一实现**：同一句人话不在两处各拼一份。

## Proposal

### 批次 A（可回源族 —— 与 L23-O1/O5 拆解并行，互不冲突）

- **L23-X1 记忆因果链回放**
  任意一条记忆可回溯「它来自哪次对话的哪句话」。三态：`traceable`（带回源坐标）/ `source-gone`（来源已被删/超预算挤出）/ `incomparable`（不同代快照，锚不同形）。
  做到的证据：任取 3 条记忆回源坐标可点开原楼层。没做到：回源不到却编一个来源（判据比对坐标真存在）。
- **L23-X6 检索可解释排序**
  每条召回给分数拆解：`vector` / `recency` / `significance` / `graph` 四项**分别给值**，并给出各项权重。
  三态：`full`（四项齐）/ `partial`（部分项读不到，逐项标 `unknown`）/ `unavailable`（整体读不到）。
  做到的证据：任一召回可展开四项分项。没做到：缺项写成 `0`（把「算不出」当「不重要」）。
- **L23-X7 记忆修订历史**
  被改写多次的记忆保留修订链，可回看每版差异（人读面一行一段）。
  两态：`chained`（有 ≥1 次修订）/ `single`（只有首版，如实说「未修订过」）。
  没做到：只留最新版，历史被抹掉且无提示。

### 批次 B（跨角色族 —— 全部受「只报不裁」约束）

- **L23-X2 角色记忆偏差面**
  同一事件各角色各存一份，列出「谁记得不一样」。三态：`agree` / `diverge`（逐条列分歧）/ `incomparable`。
  **不裁决**：不擅自「纠正」某个角色，也不指定谁对——差异本身就是产品面。
  没做到：给出裁决或替角色改记忆。
- **L23-X3 承诺兑现追踪**
  跨剧情弧的承诺（谁答应谁什么 / 截止在哪个剧情点），到期未兑现必须显形。
  三态：`kept` / `pending`（未到期）/ `overdue`（已过期）。
  没做到：过期却显示「正常」；或空时编一条承诺。
- **L23-X9 跨会话延续证明**
  「我记得你上次说过」这类跨会话引用**必须附具体楼层锚**。两态：`traceable` / `untraceable`。
  没做到：回源不到却说了这句话（判据扫「跨会话措辞 + 无锚」组合）。

### 批次 C（候选与水位族）

- **L23-X4 遗忘的叙事解释**
  记忆被挤出预算时，生成「想不起来了」的**候选句素到**（candidate），由角色决定说不说。
  受**频率门**约束：权重读不到时 fail-closed **不许提**。
  没做到：替角色把话说死；或权重读不到仍然产出。
- **L23-X5 记忆冲突裁决台**
  两条冲突记忆并排：各自证据 + 时间锚 + 来源，给三种**处置候选**（保留哪条 / 合并 / 搁置）。
  **只给候选不自动裁决**——自动裁决即判据翻红。
  没做到：悄悄选了其中一条。
- **L23-X8 容量水位与淘汰预告**
  预算水位 + 「下一条会被淘汰的是哪条」。三态：`ample` / `near`（临界）/ `over`（超限）。
  **只预告不执行**：真删了就是越权。没做到：只报水位不报淘汰对象；或真执行了淘汰。

## 批次与依赖

A: X1 / X6 / X7  （可回源族，可并行于 O1/O5 拆解）
B: X2 / X3 / X9  （跨角色族，依赖 X1 的回源坐标）

## 验收（两面表）

| 项 | 做到时的证据 | 没做到时怎么被抓 |
|---|---|---|
| X1 | 任取 3 条记忆回源坐标可点到原楼层 | 编造来源 / 坐标不存在 |
| X6 | 四项分项数值可展开 | 缺项写成 0 |
| X7 | 修订链可逐版回看 | 只留最新且无提示 |
| X2 | 分歧逐条列出且不裁决 | 擅自纠正某角色 |
| X3 | `overdue` 必须显形 | 过期显示「正常」 |
| X9 | 跨会话引用带楼层锚 | 有措辞无锚 |
| X4 | 候选句素 + 频率门 fail-closed | 替角色说死 / 读不到仍产出 |
| X5 | 三种处置候选并排 | 自动裁决 |
| X8 | 水位 + 淘汰对象预告 | 只报水位 / 真执行淘汰 |
