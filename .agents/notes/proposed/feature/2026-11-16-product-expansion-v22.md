# Agent Note: LonSha 第二十二期拓展创新计划 (L22-X1 ~ L22-X9)
Status: proposed
Baseline: v3.471.0 / 18ba158
Date: 2026-11-16
Depends-on: L21 十八项 / v3.467 provision

## Problem

> 查重读数（lmp 仓 ls/grep）：
> 时间胶囊 capsule 0 / 未来信 future-letter 0 / 关系里程碑 relation-milestone 0 / 档案包 archive-pack 0 /
> 全量导出 full-export 0 / 多角色同台 multi-char 0 / 记忆体检 memory-checkup 0 / 记忆时间线 memory-timeline 0 /
> 记忆热力 heatmap 0 / 首因首忆 first-memory 0 / 记忆地图 memory-map 0 / 睡眠整理 sleep-consolid 仅 1
> 均无现成实现，属新面。判据/台账是默认纪律。

## Proposal

### 批次 A（时间与情感容器）
- **L22-X1 记忆时间胶囊**：把「某条记忆」封存到指定剧情日打开，封存期不在注入面出现，到点提醒「一封封存的记忆可以打开了」。三态：封存中/可开/已开。
- **L22-X2 给未来的信**：玩家或角色写一段给未来自己的话，到剧情日回响。候选不替角色选，只产「可回响」候选。
- **L22-X3 关系里程碑**：把「第一次见面 / 第一次争吵 / 第一次和好」这类关系节点从既有图谱里抽成里程碑时间线，可回看。

### 批次 B（体检与地图）
- **L22-X4 记忆体检**：一键报告记忆库的健康度（冲突数/过期数/零消费数/重复数），每项可点进去。只读。
- **L22-X5 记忆时间线**：把散落各处的记忆按剧情钟排成一条可滚动时间线，点击回源。
- **L22-X6 记忆地图**：把关系图谱投影成可缩放的主题地图（人物/事件/地点），点击高亮相关边。

### 批次 C（沉淀与导出）
- **L22-X7 睡眠整理**：剧情夜间「整理记忆」——把低显著度记忆压缩、重要记忆固化，产一份「昨夜整理了 N 条」的可读摘要。
- **L22-X8 记忆档案包导出**：把一段剧情范围的全部记忆打成一个可回放的包（只导出不含隐私键），可另存。
- **L22-X9 多角色同台记忆隔离**：当多角色同场时，各角色的私有记忆互不可见，共享记忆单独成面。三态：私有/共享/不可比。

## 纪律（默认）
候选不替角色选；桥只判不写；读不到 ≠ 没事；判据正反两面 + 负控制；版本同源；提交推送。

## 验收（两面）
每项写「做到时的证据」与「没做到时怎么被抓」。
