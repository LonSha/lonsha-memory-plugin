# Agent Note: LonSha 第十五期优化提升计划
Status: proposed
## Problem
第十四期和具身在场统一桥交付后，记忆插件已具备微观物理现场快照（L0 Scene State）与在场路由防穿透能力（Presence Routing Guard）。然而，已有机制在跨轮会话持久化、纠错级联扩散、动态选材注意力预算调节、以及跨周目迁移的差异可视化比对上，仍存在深层产品使用断点。本计划以 2026-11-06 本地源码（v3.446.0）为基线展开。

## Proposal
将已有内核能力贯通到真实宿主消费闭环：严禁纯内核单跑，必须实现数据Owner、控制器、宿主接线、诊断行、主生成注入管线及 Settings UI 的全链路垂直贯通。与拓展创新九项共 18 项，两仓共 36 项。

### L15-O1 · 具身在场状态与跨轮场景生命周期的快照持久化
- **现有底座与差距**：`scene-state-tracker.js` 与 `presence-routing-guard.js` 已实现单轮在场计算与防穿透拦截，但换会话或刷新后现场快照未落盘进长局存档，易退化为无状态孤岛。
- **本期交付**：将 L0 场景状态纳入长局会话快照持久化，支持跨轮会话恢复、异常退出重载及场景切换时的状态结转，提供只读快照恢复接口。
- **玩家入口**：Settings UI 事实与场景工作台「🎭 物理现场快照」状态卡片及 oplog 审计面。
- **验收旅程**：在会话中设置地点与在场角色，刷新/重载会话后现场快照完整无损；场景切换时前序快照沉淀进历史，不产生幽灵角色污染。
- **实施规模**：L，包含数据持久化、宿主取库桩、诊断面、Settings UI 呈现及定向验证套件。

### L15-O2 · 检索消歧的跨角色人际动态图谱权重加成
- **现有底座与差距**：`engine-recall.js` 具备基础别名与偏好解析，但在多角色同名异人或称谓重叠时，未结合关系图谱（`graphEdges`）与交互亲密度进行自适应动态加权。
- **本期交付**：引入人际图谱关系亲密度加权算子，在召回候选消歧阶段动态加权当前主互动角色的强关联事实，降低背景边缘角色的噪音命中率。
- **玩家入口**：召回结果详情与人物消歧解释面板。
- **验收旅程**：同名人物在不同人际网络中被准确消歧，与主角具有深厚关系的人物事实优先命中；移除关系边后权重即刻复原。
- **实施规模**：L，包含图谱解析、召回流水线插桩、诊断行及定向断言。

### L15-O3 · 事实纠错影响扩散与派生版本演化树
- **现有底座与差距**：纠错台支持修改单一事实，但缺乏派生推理事实、视角投影与下游图谱的级联影响分析树，纠错后旧派生事实仍可能滞留。
- **本期交付**：构建事实纠错级联追踪器，单条事实被纠错时生成影响分析树，标记并撤销依赖该事实的派生条目，生成版本演化链条与回溯点。
- **玩家入口**：事实条目编辑→「纠错级联影响树」预览→确认执行。
- **验收旅程**：纠正根事实后，其下游派生结论同步标记为过时并在检索中静默；执行撤销时完整恢复原始版本。
- **实施规模**：L，包含依赖关系解析、版本树数据结构、UI 预览组件及破坏负控制。

### L15-O4 · 动态长篇选材的注意力预算自适应弹性调节
- **现有底座与差距**：`generation-memory-plan.js` 具备硬性预算截断，但在长局对话节奏紧凑或松散切换时，缺乏自适应弹性伸缩机制。
- **本期交付**：根据当前场景紧张度（`sceneState.tension`）与交互密集度，动态弹性调整事实召回密度与硬预算上限，高张力场景精简提纯、低张力场景适度丰富。
- **玩家入口**：主注入管线回执与设置面板预算滑块动态指示。
- **验收旅程**：高张力对抗场景下注入 Token 严格收敛至精炼核心事实；松弛闲聊场景下自适应释放预算召回回忆，无硬性溢出。
- **实施规模**：L，包含节奏感知、预算分配器、主注入接线及端到端断言。

### L15-O5 · 记忆事实有效期的剧情日历时间戳与因果双锚定
- **现有底座与差距**：双时间机制（发生时间/得知时间）虽有模型，但未与剧情日历（年月日系统）形成双向时钟映射，跳日或倒叙时易出现时间矛盾。
- **本期交付**：统一剧情日历时钟映射，将事实有效期绑定至绝对日历与故事事件锚点，提供时间穿越矛盾拦截器。
- **玩家入口**：时间线筛选器与事实详情时间标尺。
- **验收旅程**：过去某日发生且在次日失效的事实，在后续剧情中自动归入历史记忆不再作为现状注入；倒叙叙事时明确标记得知时间。
- **实施规模**：L，包含日历解析器、有效性门禁、时间线视图扩展及测试套件。

### L15-O6 · 记忆迁移包的周目差异可视化比对与增量合并
- **现有底座与差距**：`memory-migrate-pack.js` 支持全量导入导出与冲突三档决策，但不支持跨周目/跨分支存档的差异可视化对比与增量勾选合并。
- **本期交付**：在迁移面板提供周目存档 Diff 查看器，展示新增、冲突与修改的事实项，支持玩家按模块/条目进行增量挑拣合并。
- **玩家入口**：Settings UI 记忆迁移面板「增量对比合并」工作区。
- **验收旅程**：导入不同分支存档，界面如实渲染差异清单；玩家勾选部分条目合并后，未勾选项不覆盖本地，合入项校验通过。
- **实施规模**：L，包含差异对比算法、宿主合并事务、UI 交互及定向测试。

### L15-O7 · 符号与向量混合检索的高并发吞吐优化
- **现有底座与差距**：大体量记忆（超万条）下全表遍历与相似度计算耗时显著增加，缺乏基于内存倒排分桶的分级预筛缓存。
- **本期交付**：构建双层预筛缓存池，前置利用实体词与时空标签进行分桶粗筛，仅对高质量候选集执行向量精排与重打分。
- **玩家入口**：检索诊断行与耗时指标监控。
- **验收旅程**：在万级事实规模测试集下，检索吞吐量与平均延迟显著优化，粗筛准确率不漏判核心高优先级事实。
- **实施规模**：L，包含倒排索引结构、缓存淘汰策略、压测套件及精度断言。

### L15-O8 · 跨楼层证据引用的正文局部编辑自愈重新锚定
- **现有底座与差距**：当对话历史楼层正文被用户或宿主编辑时，依赖字符偏移量或哈希的证据引用容易直接断裂或指向错误区域。
- **本期交付**：实现证据引用自愈器，基于局部文本语境指纹与编辑距离自适应重新定位证据在楼层正文中的真实范围，无法定位时显式降级标记。
- **玩家入口**：事实引证来源链接与正文回溯高亮。
- **验收旅程**：原楼层插入前缀或局部修改词句后，证据引用自动重算并精确命中目标句子；大幅删改时显式提示引用需复核。
- **实施规模**：L，包含模糊对齐算子、自愈修复链路、诊断行及定向断言。

### L15-O9 · 记忆维护中心的主动健康巡检与逻辑矛盾预警
- **现有底座与差距**：维护中心仅具备静态孤儿检查，缺乏跨事实、跨人物关系的逻辑自洽性主动巡检与矛盾探测机制。
- **本期交付**：构建记忆健康主动巡检器，扫描相互抵触的事实对（如状态互斥、生死矛盾、时空瞬移），并在维护面板提供一键调解入口。
- **玩家入口**：维护中心「逻辑健康度」卡片与矛盾警报通知。
- **验收旅程**：主动巡检查出注入的矛盾事实并标红原因；调解确认后更新主事实并封存旧事实，消除警报。
- **实施规模**：L，包含矛盾检测规则池、调解工作台、宿主修复接口及测试套件。
