> 读数见 docs/planning/2026-11-17-product-evidence-v23.md（两仓共用一份证据书）。
> 判据 / 台账是每项默认纪律，不占名额。
> **本期不新增孤岛引擎**：优化九项全部是「已经登记但没收口」的存量账。

1. `index.js` **13546 行**单文件，装配/注册/生命周期混在一处。L22-O1 声称已拆，实测未拆。⇒ L23-O1
2. `load_surface_only_count = 11`，L22-O7 声称已处置，实测未变。⇒ L23-O2
3. `zero_consumption_count = 1` 仍挂着。⇒ L23-O3
4. `realhost_readings.verdict = environment-unavailable`，生成器在写但**无门在读**。⇒ L23-O4
5. `engine-diagnostic-lines.js` **5915 行**，第二大文件，**从未进过任何拆解计划**。⇒ L23-O5

## Proposal

### 批次 A（结构拆解 —— 只搬不改，风险最高先做且最严）
- **L23-O1 拆 `index.js`**：按「装配 / 注册 / 生命周期 / 事件」分文件。
  **行为等价判据三条**：① 导出面键集合逐字不变；② 同一批 fixture 快照对拍**零差异**；③ 既有 529 套判据全绿。
  出现任一差异 ⇒ 回头改搬运方式，**不许改判据、不许放宽上界**。
- **L23-O5 拆 `engine-diagnostic-lines.js`**：按诊断族分组（结构自检 / 健康读数 / 回归对照 / 覆写面），
  同 O1 三条等价判据。此文件此前无上界门 ⇒ 拆完补行数上界判据，防再长回去。

### 批次 B（台账收口 —— 不许「待后续」）
- **L23-O2** 11 个 `load_surface_only` 逐个定性：`wired`（真接业务调用链）或 `declared_dormant`（保留文件、不冒充能力）。
  判据读台账字段，`load_surface_only_count` 必须归 0；理由字段**禁止**出现「待后续」字样（扫描器硬拦）。
- **L23-O3** 唯一一个零消费模块接线或归档，`zero_consumption_count` 归 0。
  负控制：把消费点注释掉，判据必须翻红（证明它真的在看调用链，不是在看字符串）。
- **L23-O6** 「写了不读」键 / 字段级扫描，产出可处置清单。
  **空清单必须自证**：扫描器要打印「扫了多少文件 / 多少键 / 多少读点」，全 0 时说「没扫到」而不是「没有问题」。

### 批次 C（门与诊断面）
- **L23-O4 realhost 门**：`available` ⇒ 必须有读数且过阈值；`unavailable` ⇒ 必须如实记 `cause`。
  **两态不同形**（不同 JSON 形状 + 不同判据分支），不许压成一句「没环境」。
- **L23-O9 冻读取新鲜度**：冻读取集合带时间戳，三态 `fresh`(<30d) / `stale`(<90d) / `expired`(≥90d)，
  过期即红并给**可复制**刷新命令；**缺时间戳一律判 `expired`**（fail-closed）。
- **L23-O7 注入回执全分面**：覆盖全部注入路径，含失败 / 跳过 / 降级，每面不同形
  （沿用 `_assembly_receipt_judge.mjs` 的 `silent` / `lied` / `swapped` 三档，不许合成一个布尔）。
- **L23-O8 视图真开**：34 个分支逐个**真调**，判三条：① 不抛错；② 产物落 DOM；③ 带机器可读面态。
  负控制：单视图取数注入必抛 ⇒ 被收口成 `failed` 面不炸面板、其余视图不连坐，`empty` 与 `failed` 不同形。

## 批次与依赖

```
A: O1 / O5（拆解，最严等价判据）
B: O2 / O3 / O6（台账，全部禁止「待后续」）
C: O4 / O9 / O7 / O8（门与诊断面）
```

A 与 B 可并行（不同文件），C 依赖 A 完成（拆完后行数与面态才稳定）。

## 纪律（默认，不占名额）

- 判据正反两面 + 负控制；**负控制必须真破坏源码，不是真值表打勾**。
- 台账读数机器生成，不手抄；版本六源同源。
- **关键词命中数不能当判据**（本期教训，见证据书 §0.2）：判定「已交付」只认判据真跑 / 台账真读数 / 真调用链。
- 发现账实不符**先记账**，不许用一个「补登」把「没做」和「做了」抹平成同一件事。
- 每条交付附「做到时的证据」与「没做到时怎么被抓」。

## 验收（两面表）

| 项 | 做到时的证据 | 没做到时怎么被抓 |
|---|---|---|
| O1 | 导出面逐字不变 + 快照零差异 + 529 套绿 | 任一键缺失或快照有一字符差异 |
| O5 | 同上 + 新行数上界判据绿 | 拆完行数不降 / 上界门缺失 |
| O2 | `load_surface_only_count === 0` | 计数 >0；或理由含「待后续」 |
| O3 | `zero_consumption_count === 0` | 注释掉消费点后判据仍绿（假判据） |
| O6 | 清单可处置 + 扫描器自报读数 | 空清单但已知存在写了不读 |
| O4 | 两态形状不同 + 各有判据分支 | 两态塌成一句「没环境」 |
| O9 | 三态各可造 + 缺时间戳判 expired | 缺时间戳却判 fresh |
| O7 | 失败/跳过/降级各有回执面 | 任一失败路径无回执 |
| O8 | 逐分支真调三条全过 | 静态可达但真调抛错 |
