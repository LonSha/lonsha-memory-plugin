# Agent Note: LonSha 第十七期优化提升计划 (L17-O1 ~ L17-O9)
Status: proposed
Baseline: v3.460.0

## Problem
在第十六期交响总线与全引擎拓扑编排落地后，记忆引擎在宏观调配与长局感知上已具备骨架。但在长程实测中，仍存在五大深水区产品使用痛点：
1. 记忆过度诚实理性，缺乏真实人性所具备的心理防御与自尊保护主观叙事润色；
2. 关键长远伏笔与重大承诺仍处于被动搜索唤醒，缺乏角色打破问答惯性主动提起的执念驱动；
3. 四桶认知视界在代词混淆时存在微观上帝视角穿帮隐患；
4. 事实版本演化与纠错缺乏完整的下游 DAG 级联自愈能力；
5. 手机端的碎屑行为与心智中枢未能形成 0 延迟双向波纹反馈。

## Proposal
落实 9 项优化提升与 9 项拓展创新，两仓共 36 项。严格遵循真实工程标准：拒绝纯函数内核，必须具备数据持久化 Owner、主生成管线接线、诊断行、Settings UI 工作台及定向自动化门禁。

### L17-O1 · 记忆交响波纹总线（Symphony Bus）主生成管线单周期直通
- **现有底座与差距**：memory-symphony-orchestrator.js 与 engine-orchestration-ripple-bus.js 虽已就绪，但在 generation-memory-plan.js 组装提示词时存在多次分步解析开销。
- **本期交付**：重构直通管线，在主注入前单周期完成感知、因果、防御、反刍、注入五级心智梯队统一流转，消灭异步等待与幽灵状态。
- **玩家入口**：玩家主页「⚡ 心智流水线直通状态」状态指示灯。
- **验收旅程**：千轮对话下，提示词前置记忆调度延迟降至 10ms 以内，条目严格按优先级排布。

### L17-O2 · 认知视界四桶物理硬隔离防穿透仲裁器（Anti-Omniscience Guard）
- **现有底座与差距**：亲历、共历、传闻、禁区四桶在代词模糊时偶有边缘穿透。
- **本期交付**：引入主观见证凭据账本（Source Witness Ledger），强制核验当事角色是否在场或收到转述，非法事实强制熔断。
- **玩家入口**：事实卡片「🔒 角色知识权限：亲历/听闻/未知」标签。
- **验收旅程**：密室事件未在场角色，在后续交互中绝无任何全知穿帮。

### L17-O3 · 事实版本演化与信念纠错级联自愈（Cascading Belief Self-Healing）
- **现有底座与差距**：纠错单条根事实后，下游派生推论仍滞留。
- **本期交付**：构建 DAG 依赖版本演化树，根事实修改后自动使下游派生事实批量失效并重构。
- **玩家入口**：纠错工作台「🌳 级联影响演化树」预览与确认。
- **验收旅程**：澄清误会后，派生猜忌记忆自动归档为过时，角色言行回归自洽。

### L17-O4 · 万级长局记忆分层金字塔聚类与动态注意力弹性伸缩
- **现有底座与差距**：上千轮长局细碎事实增加检索开销，固定预算无法自适应张力变化。
- **本期交付**：时代纪要金字塔索引压缩，结合场景紧张度（Tension）弹性伸缩 Token 预算。
- **玩家入口**：设置面板「📊 记忆聚类金字塔与弹性预算」仪表盘。
- **验收旅程**：对抗场景注入提纯，闲聊场景自适应释放预算召回回忆。

### L17-O5 · 实体指代消歧与人际图谱关系亲密度动态加权
- **现有底座与差距**：同称谓或同名角色在多人在场时偶有张冠李戴。
- **本期交付**：结合在场上下文与图谱亲密度边权重，动态加权视线焦点角色。
- **玩家入口**：召回诊断「👥 人物消歧与图谱加权解释器」。
- **验收旅程**：多女性在场时，“她”的指代精准命中倾诉对象事实。

### L17-O6 · 剧情日历、双时钟与因果不变量主动熔断
- **现有底座与差距**：跳跃日历或倒叙时偶有时空脱节或已销毁物品复现矛盾。
- **本期交付**：统一剧情日历绝对时钟与因果逻辑时钟映射，不变量矛盾主动熔断。
- **玩家入口**：时间线筛选「⏰ 时空一致性与因果锁」。
- **验收旅程**：第三章销毁的道具绝不在第五章作为实物被角色翻出。

### L17-O7 · 记忆跨周目与多分支存档差异增量比对合并中枢
- **现有底座与差距**：跨分支存档导入缺乏可视化 Diff 与挑拣合并。
- **本期交付**：UI 提供周目 Diff 对比工作台，支持条目级增量合并。
- **玩家入口**：迁移面板「🔀 周目增量比对与挑拣合并」。
- **验收旅程**：多世界线对比清晰，可挑拣继承挚友承诺而剔除决裂记录。

### L17-O8 · 跨楼层证据引用的正文局部编辑自愈重新锚定
- **现有底座与差距**：楼层正文被用户修改或重抽后，字符偏移证据引用容易失效。
- **本期交付**：局部语义指纹自愈算法，正文变动后自动重新吸附证据片段。
- **玩家入口**：证据详情「📌 楼层锚点自愈健康度」。
- **验收旅程**：修改楼层错字语序，关联事实仍能稳定吸附对应楼层。

### L17-O9 · 玩家端极简心智诊断面板与状态无损持久化
- **现有底座与差距**：引擎运行时瞬态变量在刷新切卡时偶有漂移。
- **本期交付**：全量心智瞬态纳入持久化快照，主页升级为角色心流晴雨表。
- **玩家入口**：悬浮球主页「💖 角色心流晴雨表与羁绊看板」。
- **验收旅程**：完全重启浏览器后，情绪余韵与心流状态 100% 原位恢复。
