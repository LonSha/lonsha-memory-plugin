## 🔬 技术创新

### 1. WebGL 着色器优化

**节点着色器**
- 点精灵渲染（gl.POINTS）
- 重要性驱动大小（importance）
- 平滑抗锯齿（smoothstep）
- 发光效果（glow）

```glsl
// Fragment Shader 精髓
float dist = length(gl_PointCoord - vec2(0.5));
float alpha = 1.0 - smoothstep(0.4, 0.5, dist);
float glow = v_importance * (1.0 - dist * 2.0);
vec3 color = v_color.rgb + vec3(glow * 0.3);
```

### 2. 操作转换（OT）算法

**冲突检测**
- 同节点并发更新：时间戳决定
- 删除 vs 更新：删除优先
- 其他：并行保留

**应用场景**
- 多人同时拖拽节点
- 并发添加边
- 冲突摘要更新

### 3. 离线优先架构

**三层存储**
1. 内存（Map）：即时访问
2. IndexedDB：持久化
3. 云端（Firebase/Supabase）：跨设备同步

**数据流**
```
用户操作 → 内存更新 → 实时广播 → IndexedDB → 云端同步
         ↓
      立即渲染
```
