# LonSha 记忆引擎

一个为 SillyTavern 打造的记忆插件。

AI 角色聊着聊着就忘了之前发生的事？这个插件让对话拥有长期记忆：谁出现过、发生了什么、关系如何变化，都会被记录下来，在之后的对话中自动回忆。

**当前版本**：`3.427.0`

## 它能做什么

- **自动记忆**：从对话中提取人物、事件、关系，存进长期记忆，不用你手动操作
- **智能召回**：聊到相关内容时，自动把相关记忆注入上下文，让角色记得你
- **人物关系**：登记登场人物及其相互关系，随剧情推进更新
- **故事时间线**：把发生的事件按时间整理成时间线，随时回看剧情
- **记忆强度治理**：重要的记忆自动保护，防止被遗忘机制误删
- **多会话隔离**：每个聊天独立记忆，互不串扰

## 安装

放入 SillyTavern 的 `scripts/extensions/third-party/` 目录（或通过扩展市场安装），刷新页面即可。无需配置数据库，开箱即用。

## 快速上手

1. 在设置里填好你的 AI 接口（地址 / Key / 模型）
2. 开始聊天，引擎自动开始记忆
3. 打开记忆总览面板查看积累了什么
